# CodeAlpha Hangman Game

## Description
A simple text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

## Features
- Uses 5 predefined words
- Randomly selects a word
- Player guesses one letter at a time
- Allows a maximum of 6 wrong guesses
- Checks repeated and invalid inputs
- Displays the final result

## Technologies Used
- Python
- Random module
- Lists
- Sets
- Strings
- Loops
- Functions
- If-else conditions

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python hangman.py
